# VelaCare 5 分钟演示剧本

## 场景设定

独居老人张大爷家中安装 VelaCare 看护终端。设备持续监测环境温度、湿度、空气
异常与活动状态，并按日程提醒饮水服药。

## 演示流程

### 第 0-1 分钟：开机与首页

1. NSH 运行 `velacare --sim`，进入首页
2. 讲解首页信息：当前时间日期、风险等级（绿色「正常」）、温度/湿度/空气/活动
3. 指出「AI 分析：在线/离线」状态与本地规则兜底设计

### 第 1-2 分钟：环境监测页

4. 切到「环境」页，展示温度/湿度/空气三条趋势条与阈值说明
5. 说明模拟数据源与真实传感器扩展方式（弱符号钩子）

### 第 2-3 分钟：阈值主动（核心亮点）

6. 切到「设置」页，点「触发演示异常（燃气/高温）」
7. 返回首页观察风险等级变化：正常 → 预警 → 紧急（颜色逐级变红），
   弹窗自动出现
8. 点「确认」完成处置；事件记录页出现该风险事件与时间
9. 说明告警联动：WARNING/EMERGENCY 时屏幕高亮 + 蜂鸣器/LED（预留 GPIO）

### 第 3-4 分钟：定时主动提醒

10. 切到「提醒」页，点「喝水」添加提醒（演示自动设为 2 分钟后）
11. 等待弹窗「生活提醒：喝水时间到了」，点「稍后5分」
12. 说明升级机制：未确认自动升级、确认结果写进事件记录

### 第 4-5 分钟：AI 分析与总结

13. 若联网：展示 ai_agent 对风险事件的解释与照护建议（MiMo）
14. 若断网：说明自动降级到本地建议，核心功能不依赖云端
15. 切到「事件」页回看完整闭环：风险发现 → 提醒 → 确认 → 记录
16. 总结产品价值与技术要点（状态机、主动 Skill、离线可用）

## 演示要点

- 提前确认屏幕方向与触控正常（480×272）
- 提醒默认 2 分钟后触发，演示前先添加提醒再讲别的页面
- 「触发演示异常」按钮每次交替触发燃气/高温两种场景
- 若现场断网，首页状态展示「离线（本地规则）」本身就是降级演示点

## 录制建议（提交用）

- 分辨率 1280×720 以上，屏幕画面清晰
- 关键操作（异常触发、弹窗确认、事件回看）加字幕说明
- 时长 ≤ 5 分钟，mp4/mov
