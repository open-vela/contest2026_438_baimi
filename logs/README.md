# logs/ — AI Coding 日志

这里放开发过程中与 AI 工具的真实对话日志，和源码一起提交。

本目录提交的是队员 **gouzhongfei** 从 Codex 导出的真实会话，不是官方模板里的 example 占位。

## 目录结构

```text
logs/
└── gouzhongfei/
    ├── manifest.json
    └── <date>/
        └── codex__<sid>.jsonl
```

- 工具名：`codex`
- 每个 `.jsonl` 每行一个事件
- 只提交 JSONL 本身和清单，不提交截图冒充日志

导出说明见[《AI Coding 日志归集与提交手册》](https://github.com/open-vela/docs/blob/dev-ai-contest-2026/zh-cn/contest_2026/ai_coding_log_guide.md)。
