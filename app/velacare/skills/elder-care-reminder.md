# elder-care-reminder

主动式老人生活提醒：按预设时间执行饮水、服药、作息提醒，并支持确认与升级。

## When to use

- 到达预设的饮水/服药/作息时间
- 用户询问今天有哪些提醒
- 提醒未被确认时进行升级或稍后提醒

## How to use

1. 查询预设提醒清单（时间、内容、启用状态）
2. 到点主动推送提醒，等待确认
3. 未确认时支持稍后提醒（默认 5 分钟）与超时升级
4. 记录确认结果与处置过程到事件记录
5. 断网时同样按时推送，不依赖云端

## Example

```
User: 提醒我每天下午3点喝水
→ 创建提醒：喝水 15:00 每天
→ 15:00 主动推送：生活提醒：喝水时间到了
→ 用户确认或稍后5分钟
```
