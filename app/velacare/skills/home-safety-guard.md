# home-safety-guard

主动式居家安全守护：根据温湿度、空气异常和人员活动数据主动发现风险并给出处置建议。

## When to use

- 用户询问家中环境状态或风险
- 检测到高温/低温、湿度异常、燃气/烟雾模拟量超标
- 长时间未检测到人员活动
- 风险等级达到 ATTENTION / WARNING / EMERGENCY

## How to use

1. 读取当前环境采样与风险等级（温度、湿度、空气异常、活动状态）
2. 判断触发条件，输出风险等级 NORMAL/ATTENTION/WARNING/EMERGENCY/OFFLINE
3. 对 WARNING 及以上主动调用告警或通知工具
4. 用中文输出 1-3 条可执行建议（通风、关燃气、确认老人状态、联系家属等）
5. 断网或 LLM 不可用时使用本地规则与本地建议，保证离线可用

## Example

```
User: 家里温度怎么样？
→ 读取环境数据：温度 38.5°C，空气异常 82%
→ 风险等级：EMERGENCY
→ 建议：请立即确认老人安全，检查燃气阀门并通风，必要时联系家属或急救。
```
